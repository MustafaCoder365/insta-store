# متجر جاهز لصفحات الانستغرام

متجر إلكتروني بسيط لأصحاب الصفحات اللي يبيعون على انستغرام:

- الزبون يتصفح المنتجات حسب القسم، ويضيف للسلة، ويرسل الطلب على واتساب (الاسم، الهاتف، المحافظة، العنوان، المجموع).
- لوحة صاحب الصفحة (`#admin`): إضافة منتج بصورته من التلفون، السعر، القسم، الوصف، التوفر، والحذف.

**نسخة تجريبية:** المنتجات المضافة تنحفظ بمتصفح الجهاز فقط (localStorage). رقم الواتساب بـ `SHOP.whatsapp` داخل `index.html`.

صور المنتجات من [Unsplash](https://unsplash.com/license).

صُمّم بواسطة [TrueStackit](https://truestackit.com).
